# Bio App - Ứng dụng Quản lý Quy trình Canh tác

Ứng dụng Flutter hỗ trợ nông dân quản lý toàn bộ quy trình canh tác, từ vùng trồng, lô trồng, nhật ký chăm sóc đến thu hoạch, sơ chế và quản lý kho, đảm bảo tuân thủ các tiêu chuẩn chứng nhận như GACP, Organic, OCOP.

## Chức năng chính

- ✅ Quản lý Vùng trồng & Lô trồng
- ✅ Nhật ký chăm sóc với tích hợp IoT
- ✅ Thu hoạch & Sơ chế
- ✅ Quản lý Kho nguyên liệu khô & Đóng gói
- ✅ Theo dõi Chứng nhận (GACP, Organic, OCOP)

## Cài đặt

```bash
flutter pub get
flutter run
```

## Cấu trúc dự án

```
lib/
├── main.dart
├── models/          # Các model dữ liệu
├── screens/         # Các màn hình
├── widgets/         # Widget tái sử dụng
├── services/        # Services (API, Database, etc.)
├── providers/       # State management
└── utils/           # Utilities và helpers
```

## Yêu cầu

- Flutter SDK >= 3.0.0
- Dart SDK >= 3.0.0
